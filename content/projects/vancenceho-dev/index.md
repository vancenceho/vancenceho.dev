## Overview

This site is itself the first entry in the Projects section - a personal portfolio built to showcase personal software and data engineering work. Also, it also logs some of my experiences in the tech world and how I work through them, you can call it my personal tech dairy (Haha!). Lastly, while working on this site it helps me to learn the Hugo framework as well as the Blowfish theme, specifically, along the way.

## Tech Stack

- **Hugo** - static site generator
- **Blowfish** - Hugo theme (installed as a git submodule)
- **Tailwind CSS** - styling, via Blowfish's build pipeline
