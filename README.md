# Personal Portfolio - VANCENCE HO

## 🚀 Getting Started

This personal website is built as a portfolio to showcase my personal projects, skills, and achivements as a current **Computer Science** student at the **Singapore University of Technology & Design (SUTD)**. The area which I am interested in and plan to explore more in CS include Artificial Intelligence (AI), particularly in Computer Vision, and Software Engineering. This website is built with **Hugo**, **Blowfish**, and **Tailwind CSS**. 

### Pre-requisites

- Git
- brew
- hugo

### Launch

1. Enter project's directory

``` bash
cd /<HOME_DIR>/vancenceho.dev
```

2. Launch webpage

``` bash
hugo server
```
